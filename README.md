# f9c-cicd-demo

[![F9C CI/CD](https://github.com/F9Csec/f9c-cicd-demo/actions/workflows/cicd.yml/badge.svg)](https://github.com/F9Csec/f9c-cicd-demo/actions/workflows/cicd.yml)

PoC da esteira CI/CD da F9C utilizando GitHub Actions.

## Pipeline

Issue → Feature Branch → Pull Request → Test → Build → Merge → Deploy → GitHub Pages

## Tecnologias

- GitHub
- GitHub Projects
- GitHub Actions
- Node.js
- GitHub Pages

## Objetivo

Validar uma esteira CI/CD simples, rastreável e de baixo custo, centralizada no ecossistema GitHub.
